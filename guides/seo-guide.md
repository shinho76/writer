## 0. 먼저 알아둘 것: 2026년 검색 환경의 변화

1. **"키워드만 넣으면 노출되던 시대는 끝났다."** 네이버는 글자 수·키워드 반복보다 **정보의 충실성과 사용자 만족도**를 본다. 🟡
2. **AI 브리핑 도입.** 2026년 4월 연관검색어를 없애고 블로그·카페·지식iN 콘텐츠를 요약하는 AI 브리핑을 넣었다는 보도가 있다. 6월에는 대화형 검색인 AI 탭이 나왔다. 🟡 (단일 2차 출처 기반, 세부 내용은 재확인 필요)
   - 실무적 결론: AI가 **여러 문서를 합성해 인용**하므로, 질문에 곧바로 답하는 **명확한 문단 구조**와 **직접 겪은 구체적 경험**이 유리하다.
3. **"저품질 블로그"는 네이버가 공식적으로 쓰는 용어가 아니다.** 그러나 검색에서 밀리는 현상은 실제로 있으므로 아래 7장을 지켜야 한다. 🟢

## 1. 제목 작성 규칙

### 1-1. 글자 수

| 항목 | 권장값 | 신뢰도 |
|---|---|---|
| 적정 길이 | **15~25자** | 🟡 |
| 상한선 | **약 35자 이내** (모바일 검색결과에서 잘리지 않고 보이는 분량) | 🟡 |
| 절대 상한 | 60자 이내 (넘으면 손해만 있음) | 🟡 |

- 공식적으로는 **"글 내용을 대표하는 명확하고 간결한 제목"** 이라는 원칙만 있고 글자 수 기준은 없다. 🟢
- 짧을수록 좋은 것이 아니라, **모바일에서 끝까지 보이면서 내용을 정확히 알려주는 길이**가 목표다.

### 1-2. 키워드 위치

- **핵심 키워드는 제목의 앞쪽에 1회** 자연스럽게 넣는다. 🟡
- 같은 키워드를 제목에서 반복하지 않는다. 🟢 (검색어의 의도적 반복은 금지 대상)
- 핵심 키워드 + 수식 요소(숫자, 대상, 상황, 결과)로 구성한다.
  - 구조 예: `[핵심 키워드] + [구체 상황/대상] + [결과 또는 방법]`
- 숫자를 포함하면 클릭률이 오른다는 견해가 많다. 🟡 (예: `3가지`, `2주 후기`)
- 질문형 제목은 AI 검색·질의형 검색 흐름에서 유리하다는 견해가 있다. 🔴

### 1-3. 피해야 할 것

| 피할 것 | 이유 | 신뢰도 |
|---|---|---|
| 검색어를 **의도적으로 반복**한 제목 | 어뷰징 판단 대상 | 🟢 |
| **지역명·상품명 나열** 제목 (`강남 역삼 선릉 맛집 추천 베스트`) | 키워드 스터핑 | 🟢 |
| **낚시성 문구** (본문과 다른 자극적 제목, 과장) | D.I.A.+가 "오해를 부르는 제목"을 더 엄격하게 걸러냄 | 🟢 |
| **특수문자 남용** (`★★`, `!!!`, `【】` 과다) | "오히려 좋지 않은 영향" | 🟢 |
| **검색 의도와 무관한 제목** | 문서 의도 부합도 점수 하락 | 🟡 |
| **광고성 과장어** (`최고`, `1위`, `무조건`, `100%`) | 광고성으로 분류될 가능성, 신뢰도 하락 | 🟡 |
| **금칙어** (성인·도박·불법금융·유해물질 관련어) | 노출 제한·누락 위험 | 🟡 |
| 제목과 **본문 첫 문단이 어긋나는** 구성 | 이탈률 상승 → 만족도 신호 하락 | 🟡 |

## 2. 본문 구조

### 2-1. 도입-본론-결론 비율

공식 비율은 없다. 아래는 상위 노출 글에 공통으로 보이는 **권장 배분**이다. 🔴

| 구간 | 비율 | 역할 |
|---|---|---|
| **도입** | 약 10~15% | 독자 상황 공감 + **답의 요약** 또는 글의 범위 예고 |
| **본론** | 약 70~80% | 소제목별로 쟁점을 나눠 설명. 경험·수치·사진 집중 배치 |
| **결론** | 약 10~15% | 핵심 요약, 선택 기준 정리, 다음 행동 안내 |

- 정보성 글은 **결론을 먼저 말하는 역피라미드**가 잘 맞는다. 검색자는 답을 찾으러 온다.
- 도입에서 **본문 첫 100자 안에 핵심 키워드**를 넣는 것을 권하는 자료가 많다. 🟡 (자연스러울 때만)

### 2-2. 글자 수

| 항목 | 값 | 신뢰도 |
|---|---|---|
| 본문 분량 | **1,500자 이상**을 권하는 자료가 많음 | 🟡 |
| 공식 기준 | **없음.** "필요한 정보를 빠짐없이 담았는가"가 기준 | 🟢 |

- 분량을 채우려고 늘리지 않는다. **정보가 충분하면 끝낸다.**
- 300자 미만의 얇은 글을 하루에 여러 개 올리는 것은 위험하다. 🟡

### 2-3. 소제목 활용

- **소제목을 반드시 쓴다.** 상위 노출 정보성 글의 공통점으로 꼽힌다. 🟡
- 본론을 **3~5개의 소제목**으로 나눈다. 🔴
- 소제목은 **검색자가 떠올리는 질문 형태**로 쓰면 체감 효과가 크다는 평이 있다. 🔴
  - 예: `신청은 어디서 하나요?`, `비용은 얼마나 들까?`
- 소제목 **바로 아래 2~3문장에 답을 먼저** 쓰고 뒤에 부연한다. (AI 브리핑이 문단을 인용하기 쉬움) 🔴
- 소제목에도 관련 키워드를 자연스럽게 1개 정도 넣는다. 🟡
- 네이버 에디터의 **인용구·구분선·글머리 기호·표**를 써서 시각적으로 구조화한다. 가독성은 완독률(체류시간)과 연결된다. 🟡
- 문단은 **모바일 기준 3~4줄 이내**로 짧게 끊는다. 🔴

### 2-4. 글의 내용 요건 (D.I.A. 관점)

- **직접 경험한 정보**(사용 후기, 방문 과정, 실측 수치, 실패담)를 넣는다. 🟢 (경험 정보는 D.I.A.의 평가 요소로 알려져 있음)
- 결론만 쓰지 말고 **근거와 과정**을 함께 보여준다.
- 출처·기준일을 밝힌다. (`2026년 9월 기준`)
- 표·요약 박스로 **정보를 한눈에 볼 수 있게** 정리한다.

## 3. 키워드 밀도와 배치

### 3-1. 밀도

| 항목 | 값 | 신뢰도 |
|---|---|---|
| 밀도 권장 | **1.5~3%** 정도 | 🔴 |
| 공식 횟수 | **없음.** "자연스러운 문맥 속 사용"만 권장 | 🟢 |

- 밀도 수치는 참고용이다. **소리 내어 읽었을 때 어색하면 과한 것**이다.
- 예: 본문 1,500자 기준이라면 핵심 키워드는 **대략 5~8회 이내**가 자연스러운 수준이다. (계산은 참고용)

### 3-2. 배치

| 위치 | 방법 |
|---|---|
| **제목** | 앞쪽에 1회 |
| **도입 첫 100자** | 1회 (억지스러우면 생략) |
| **소제목** | 관련 키워드 또는 변형어를 1~2개 |
| **본문** | 고르게 분산. 한 문단에 몰아 쓰지 않음 |
| **마무리** | 요약 문장에 1회 |
| **이미지 설명(캡션)** | 자연스러운 문장으로 |

### 3-3. 변형어·연관어 활용 (중요)

- 같은 단어만 반복하지 말고 **동의어·연관어·세부 표현**으로 바꿔 쓴다. (`추천` → `고르는 기준`, `후기`, `비교`)
- D.I.A.는 **검색 의도**를 분석하므로, 정확한 키워드 일치보다 **의도에 대한 답의 충실성**이 중요하다. 🟡
- **롱테일 키워드**(구체적·의도가 뚜렷한 검색어)로 접근하면 신규 블로그에도 기회가 있다. 🟡

## 4. 이미지

### 4-1. 장수

| 항목 | 값 | 신뢰도 |
|---|---|---|
| 적정 장수 | **5~10장** (1,500자 기준) | 🔴 |
| 공식 기준 | **없음.** 본문과 직접 관련된 자료만 사용 | 🟢 |

- **직접 촬영한 사진**을 우선한다. 출처 불명의 도용 이미지는 위험하다. 🟡
- 이미지만 나열하지 말고 **이미지 핵심 내용은 텍스트로도 작성**한다. 🟢
- 이미지 사이에 **텍스트를 충분히** 둔다. 이미지 위주, 글자 적은 글은 정보성이 낮게 평가될 수 있다. 🟡
- 스톡 이미지·캡처 남용, 같은 사진 재사용은 피한다. 🟡

### 4-2. alt 텍스트 (대체 텍스트)

- **네이버 블로그 에디터는 이미지 alt 텍스트를 직접 입력하는 기능을 제공하지 않는다**는 자료가 있다. 🟡 (스마트에디터 업데이트로 바뀔 수 있으니 에디터에서 직접 확인)
- 대신 아래 방법으로 이미지 의미를 검색엔진에 전달한다.
  - **이미지 바로 위·아래에 설명 문장(캡션)을 쓴다.** 🟢 (핵심 내용을 텍스트로 쓰라는 공식 권고와 일치)
  - **사진 파일명**을 의미 있게 지정한다. 🔴
  - 티스토리·워드프레스 등 alt 입력이 가능한 환경이라면 아래 원칙을 지킨다. (일반 웹 접근성 기준)
    - 125자 이내, `~의 이미지`·`~하는 사진` 같은 군더더기 생략
    - 이미지가 **무엇을 보여주는지** 구체적으로 서술
    - 장식용 이미지는 비워둔다
    - 키워드를 억지로 넣지 않는다

### 4-3. 대표 이미지(썸네일) 규격

네이버 공식 수치는 확인하지 못했다. 자료마다 조금씩 다르지만 공통 방향은 아래와 같다. 🔴

| 항목 | 권장 |
|---|---|
| **안전 규격** | **1:1 비율, 800×800px** (PC·모바일 검색결과·이웃 피드에서 잘림 최소) |
| **PC 기본** | 3:2 비율, **1300×885px** 안팎 |
| 모바일 | 1:1로 자동 크롭되는 경우가 많음 |
| 공유(SNS) | 16:9로 크롭될 수 있음 |
| 형식 | JPG·PNG, 용량은 과하지 않게(수 MB 이내) |

- **핵심 피사체를 정중앙**에 둔다. (가장자리가 잘려도 의미가 유지되도록)
- 대표 이미지는 **"눈에 들어오는 핵심 이미지 한 장"** 이라는 원칙을 따른다. 🟢
- 이미지 안 **글자는 크고 짧게**. 작은 글씨는 모바일에서 읽히지 않는다.
- 제목과 **관련 없는 자극적 이미지**는 피한다.

## 5. 해시태그(태그)

### 5-1. 실제 효과

- 태그는 **글의 주제·분류를 알려주는 색인 기능**이 본질이다. 🟡
- 모바일에서는 같은 태그가 달린 글을 모아 보여주는 기능이 있어 소폭 유입이 생길 수 있다. 🟡
- 그러나 **블로그는 검색 유입이 중심이라 태그 유입 비중은 매우 작다.** 태그 최적화에 시간을 많이 쓸 필요가 없다. 🟡
- 태그 개수·순서에 대한 **공식 문서는 확인되지 않았다.**

### 5-2. 권장 사용법

| 항목 | 권장 | 신뢰도 |
|---|---|---|
| 개수 | **5~10개** 이내 (많다고 유리하지 않음) | 🔴 |
| 구성 | **핵심 키워드 1~2개 + 세부·연관 키워드 + 상황/대상 키워드** | 🔴 |
| 내용 | **본문과 실제로 관련된** 태그만 | 🟡 |
| 형태 | 띄어쓰기 없는 짧은 명사구 | 🔴 |

### 5-3. 피할 것

- 본문과 무관한 **인기 태그 끼워넣기**
- 같은 의미를 살짝 바꿔 **도배**하는 태그
- 지역명·상호 **무작위 나열**
- 제목·본문에서 다루지 않은 주제의 태그

## 6. C-Rank, D.I.A. / D.I.A.+ 가 좋아하는 패턴

### 6-1. 개념 정리

| 알고리즘 | 무엇을 평가하나 | 단위 |
|---|---|---|
| **C-Rank** | **블로그(창작자)의 신뢰도** — "이 블로그가 믿을 만한가" | 블로그 전체 |
| **D.I.A.** | **개별 문서의 품질** — "이 글이 검색 의도에 맞는 좋은 글인가" | 게시글 1건 |
| **D.I.A.+** | D.I.A.의 보완. 검색 의도 분석을 더 깊게 하고 **오해를 부르는 제목을 더 엄격히** 판별 | 게시글 1건 |

- 두 로직은 함께 작동한다. C-Rank가 높아도 글 품질이 D.I.A. 기준에 못 미치면 상위에 못 오른다. 반대로 **신규 블로그도 D.I.A.+로 좋은 글을 쓰면 기회가 있다.** 🟡

### 6-2. C-Rank 4요소 (Context · Content · Chain · Creator) 🟢

| 요소 | 의미 | 실천 |
|---|---|---|
| **Context** | 특정 주제에 대한 **집중도** | 한 블로그에서 **핵심 주제 1~2개**를 꾸준히 다룬다. 잡다한 일상글을 섞으면 불리 |
| **Content** | 생산하는 **정보의 품질** | 독창적·구체적·정확한 정보. 출처와 근거 제시 |
| **Chain** | 콘텐츠가 **소비·공유되는 연결성** | 이웃·독자의 자연스러운 방문, 공감, 댓글, 공유 |
| **Creator** | 블로거의 **전반적 신뢰·인지도** | 꾸준한 운영 이력, 일관된 활동 |

### 6-3. D.I.A. 평가 요소 🟡 (2차 자료가 정리한 요소)

- **문서 적합성**: 검색어와 문서의 의도가 맞는가
- **경험 정보**: 직접 경험한 내용이 담겼는가
- **정보 충실성**: 필요한 정보를 빠짐없이 담았는가
- **의도 부합도**: 제목이 내용을 정확히 대표하는가
- **독창성**: 다른 글을 베끼거나 짜깁기하지 않았는가
- **적시성**: 최신 정보인가 (기준일·업데이트 표기)
- **사용자 반응**: 체류시간, 이탈률, 공감·댓글 등

### 6-4. 알고리즘이 좋아하는 패턴 (실천 목록)

1. **주제 집중**: 카테고리를 한두 분야로 좁히고 그 안에서 깊이를 쌓는다.
2. **경험 기반 정보**: "직접 해보니", 실측 수치, 비교·실패 사례, 직접 찍은 사진.
3. **검색 의도에 정확한 답**: 소제목마다 질문 → 즉답 → 근거.
4. **제목과 내용의 일치**: 제목이 약속한 것을 본문이 전부 채운다.
5. **읽기 쉬운 구조**: 소제목, 짧은 문단, 표·목록. 완독률과 체류시간을 높인다.
6. **최신성 관리**: 발행일·기준일 표기, 오래된 글의 정기 업데이트.
7. **꾸준하되 억지 없는 발행**: 일정한 리듬. (매일 발행이 필수는 아니다. 네이버도 "매일 쓸 필요 없다"는 취지로 안내했다는 자료가 있다) 🟡
8. **광고성 명시와 균형**: 협찬·체험단은 **명확히 표기**하고, 비율을 과도하게 높이지 않는다. 🟢 (표기 의무) / 🔴 (30% 이하 권장은 추정)
9. **본문 내 자연스러운 정보 연결**: 같은 블로그의 관련 글로 이어지는 내부 링크(과하지 않게).
10. **AI 활용 시 독창 요소 확보**: AI가 만든 초안에 **직접 경험·실측 데이터·개인 관점**을 반드시 보태 편집한다. AI 대량 생성 콘텐츠는 위험하다. 🟡

## 7. 어뷰징으로 판정되는 것들 (피해야 할 것)

> 네이버가 판정 기준을 수치로 공개한 적은 없다. **"공식 원칙" 항목은 반드시 피하고, "추정" 항목은 보수적으로 받아들이는 것이 안전하다.**

### 7-1. 콘텐츠 관련

| 행위 | 설명 | 신뢰도 |
|---|---|---|
| **유사 문서·복붙** | 제목·본문·사진·영상이 일정 수준 이상 비슷한 글 (자기 글끼리도 해당) | 🟢 원칙 / 기준 수치는 비공개 |
| **키워드 스터핑** | 부자연스러운 키워드 나열, 검색 노출만을 위한 동일 어구 반복 | 🟢 |
| **지역명·상품명 나열** | 제목·본문·태그에 검색어를 줄줄이 나열 | 🟢 |
| **낚시성 제목** | 내용과 다른 과장·자극 제목 | 🟢 |
| **짜깁기·도용** | 남의 글·이미지·정보를 조합해 만든 글 | 🟢 |
| **AI 대량 생성 후 무편집 발행** | 독창성·경험 정보 부재 | 🟡 |
| **정보 없는 얇은 글 대량 발행** | 300자 미만 글을 하루에 여러 개 | 🔴 |
| **발행 횟수 채우기식 작성** | 정보 가치보다 횟수를 우선하는 글쓰기 | 🟢 |
| **광고·협찬 미표기** | 대가를 받고도 밝히지 않음 | 🟢 |
| **광고성 글 과다** | 광고·체험단 글 비중이 지나치게 높음 (30% 이하 권장은 추정) | 🔴 |
| **금칙어 콘텐츠** | 성인·도박·불법금융·유해물질 | 🟡 |

### 7-2. 활동·운영 관련

| 행위 | 설명 | 신뢰도 |
|---|---|---|
| **댓글·공감·방문·스크랩 조작** | 여러 계정이나 프로그램으로 반응을 만드는 행위 | 🟢 |
| **자동화 프로그램 사용** | 자동 발행·자동 댓글·자동 이웃 추가 등 | 🟢 |
| **품앗이·상호 공감 그룹** | 조직적 상호 반응 교환 | 🟡 |
| **하루 10개 이상 대량 발행** | 갑작스러운 비정상 발행 패턴 | 🔴 |
| **비정상 유입 (트래픽 조작)** | 유입 부풀리기, 유료 트래픽 | 🟢 |
| **블로그 판매·계정 양도 후 주제 급변** | 주제 일관성이 깨짐 | 🔴 |
| **링크 스팸** | 본문·댓글에 무관한 외부 링크 도배 | 🟡 |
| **무관한 주제의 글 무더기 발행** | Context(주제 집중도) 훼손 | 🟡 |

### 7-3. 저품질 의심 신호 (자가 점검)

- 글 **제목을 그대로 검색해도 VIEW 탭에 나타나지 않는다.**
- 새 글 발행 후 **며칠이 지나도 검색 반영이 안 된다.**
- 대부분의 키워드에서 **갑자기 동시에 노출이 사라졌다.**
- 이웃 새글 피드·RSS 배포가 되지 않는다.

이런 신호가 있으면:
1. 서치어드바이저에서 **수집 오류·색인 상태**를 점검한다. (robots.txt 차단, 404, 서버 오류 등)
2. **유사 문서, 키워드 반복, 광고성 글**을 정리(수정·삭제)한다.
3. **인위적 반응 조작**을 중단한다.
4. **1~3개월 정도 정직하고 꾸준하게** 운영하며 회복을 기다린다. 🔴 (기간은 경험적 추정)

## 8. 발행 전 체크리스트

**제목**
- [ ] 15~25자(최대 35자 이내)인가?
- [ ] 핵심 키워드가 앞쪽에 1회만 들어갔는가?
- [ ] 지역명 나열, 낚시성 문구, 특수문자 남용이 없는가?
- [ ] 본문이 제목의 약속을 모두 채우는가?

**본문**
- [ ] 도입 첫 문단에서 독자의 상황과 답의 방향을 밝혔는가?
- [ ] 소제목이 3~5개이고 검색자의 질문에 대응하는가?
- [ ] 소제목 아래 2~3문장 안에 답을 먼저 썼는가?
- [ ] **직접 겪은 경험, 실측 수치, 근거**가 들어갔는가?
- [ ] 기준일·출처를 표기했는가?
- [ ] 문단이 모바일 기준 3~4줄 이내인가?

**키워드**
- [ ] 소리 내어 읽어도 어색하지 않은 밀도인가? (대략 1.5~3%)
- [ ] 동의어·연관어를 섞어 썼는가?

**이미지**
- [ ] 직접 촬영한 사진이 중심인가? (5~10장 안팎)
- [ ] 이미지마다 위·아래에 설명 문장이 있는가?
- [ ] 대표 이미지가 1:1 또는 3:2에서 잘려도 핵심이 보이는가?

**태그**
- [ ] 본문과 관련된 태그 5~10개 이내인가?

**어뷰징 점검**
- [ ] 다른 글과 제목·본문·사진이 비슷하지 않은가?
- [ ] 협찬·광고를 명확히 표기했는가?
- [ ] 금칙어·과장 표현이 없는가?
- [ ] 반응 조작이나 자동화 도구를 쓰지 않았는가?
